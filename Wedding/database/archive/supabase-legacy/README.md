# Archived: Supabase version (not used)

These files are from the first version of the wedding website, which ran on Supabase (Postgres, Storage, Auth and an Edge Function).

The site now runs on MySQL through `Wedding/server`. **Nothing reads these files:** no code imports them and no deployment uses them. Every table, constraint, RLS policy and database function in them was reviewed and carried over. See "Supabase → MySQL mapping" in [`../../README.md`](../../README.md).

They're kept only for reference. Delete this folder whenever you like.
